# kadrell-ext-ssh

Kadrell extension: lists the hosts from `~/.ssh/config` in the left dock. One click opens a remote tile (ssh, attached to the host's tmux, or its normal shell if there is no tmux).

## Install

Inside [Kadrell](https://kadrell.malura.de), press `F4`, search under "Discover" for `kadrell-ext-ssh` and click Install.

Or clone it by hand:

```bash
git clone https://github.com/maluramichael/kadrell-ext-ssh ~/.config/kadrell/extensions/ssh
```

Then enable it in the `F4` dialog.
